# Face Recognition 

Recognize and manipulate faces from Python or from the command line[cite: 2].

## Overview
This project is built using the `face_recognition` library[cite: 2], powered by dlib’s state-of-the-art face recognition deep learning models. It achieves a 99.38% accuracy score on the Labeled Faces in the Wild (LFW) benchmark, allowing you to easily build applications that detect, identify, and analyze faces.

## Key Features
* **Face Detection:** Find all faces located in any given image[cite: 2].
* **Facial Landmarks:** Identify specific facial features like eyes, nose, mouth, and chin.
* **Face Identification:** Compare known and unknown faces using 128-dimension facial encodings.
* **Command-Line & Python Support:** Run face detection scripts directly from Python or via terminal command-line utilities[cite: 2].

## Requirements
* Python 3.x[cite: 2]
* dlib >= 19.7[cite: 2]
* face_recognition_models >= 0.3.0[cite: 2]
* numpy[cite: 2]
* Click >= 6.0[cite: 2]
* Pillow[cite: 2]
